# Orbilect SEO Client Proposal Template

Reusable reference: **Orbilect SEO Client Proposal Template v1**.

- `content/proposal.js` contains the client details, prices, payment split, deliverables, dates, stack, and commercial terms.
- `app/page.js` contains the page sections.
- `app/globals.css` contains the Orbilect SEO theme.
- `components/Experience.js` contains the interactive preview and scroll effects.
- `PROPOSAL-PROMPT.md` is the prompt for reusing this project.

Run `npm ci`, then `npm run dev`. Open http://localhost:3012.
Run `npm run build` before deployment.
Duplicate the project for a new client and edit the content file. Review the preview copy,
proposal metadata, links, commercial terms, and deliverable count before publishing.
